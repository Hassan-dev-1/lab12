# Sharif Biryani Corner – Lab 12

## Website pages
- `index.html` – home page
- `menu.html` – menu and prices from Lab 11
- `gallery.html` – six-image gallery
- `style.css` – shared orange/yellow styling and Arial font
- `images/biryani.jfif` – supplied biryani image

## Run locally
Open `index.html` in a browser. Keep the `images` folder beside the HTML files.

## Important
The gallery currently reuses the one supplied photo because only one food image was provided. Replace repeated copies with other food photos if you have them.
